server command
uvicorn app.app:app --port 8000 --workers 4

Alembic
Create migration -> alembic revision --autogenerate -m "tu_mensaje_aqui"
Apply migrations -> alembic upgrade head

ruff
Linting -> uv run ruff check app/
Imports -> uv run ruff check --select I app/
Format  -> uv run ruff format app/

tests
tests -> uv run pytest tests -v
coverage -> uv run pytest tests -v --cov=app --cov-report=term-missing
load -> uv run locust -f tests/load/locustfile.py --host=http://localhost:8000
